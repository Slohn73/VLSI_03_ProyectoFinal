## Descripción del Proyecto

El objetivo principal de este proyecto es diseñar e implementar un robot móvil autónomo controlado íntegramente mediante una tarjeta **FPGA** (programada en VHDL), sin el uso de microcontroladores.

El robot está diseñado para desplazarse dentro de una arena de 1 m x 1.7 m con dimensiones máximas de 20 cm x 20 cm x 20 cm. Su tarea consiste en localizar una fuente luminosa (meta) y avanzar hacia ella de manera autónoma, esquivando los obstáculos en su camino y recuperándose en caso de quedar atascado.
